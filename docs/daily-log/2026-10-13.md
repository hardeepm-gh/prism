## What learned
- RBAC = ServiceAccount (identity for pod) + minimal Role (what verbs on which resources) + RoleBinding
- Least privilege: correlator-sa can get configmaps/secrets YES, list pods NO, delete all-namespaces NO
- ClusterRoleBinding cluster-admin = DANGEROUS - if compromised, attacker owns cluster
- Default SA has no permissions - must specify serviceAccountName in Deployment
